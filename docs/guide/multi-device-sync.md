# 多设备同步

## 苹果生态跨设备传递的痛点：剪切板历史

苹果生态的 “通用剪切板” 能实现 Mac、iPhone、iPad 间内容的快速复制粘贴，提高工作效率。但它存在一个明显缺陷：新复制的内容会覆盖旧内容，用户无法在其他设备找回历史复制信息，使用时常常产生不便。

PasteQ App 正是为解决这一问题而开发的剪切板增强工具。在 macOS 端，它无需用户手动操作，便能自动记录所有的复制历史，无论是代码片段、文案内容，还是链接地址，都能完整留存。同时，其核心功能是通过 iCloud 实现剪切板历史记录的跨设备同步，在 Mac 上复制的内容会自动同步到 iPhone 和 iPad，反之亦然，让用户拥有跨设备共享的剪切板历史云。

比如在 Mac 上处理工作时，你将一些通用的邮件回复话术复制到剪切板。当你离开电脑外出，需要回复他人邮件，此时打开手机，无需重新翻找或输入，在 PasteQ App 中就能找到 Mac 上复制的这些话术，快速完成邮件回复。

此外，PasteQ App 功能丰富：支持文本、图片、链接、文件等多种格式；遇到链接会自动抓取标题和缩略图；用户可将常用内容分组收藏；数据存储在个人 iCloud 账户，保障隐私。

如果你常因苹果通用剪切板无法保存历史记录而困扰，PasteQ App 或许能帮你提升设备使用效率。
