# 在 iPhone 上用 PasteQ 键盘输入常用文本

PasteQ 键盘让您点选已保存的常用回复、邮箱地址或文本片段，填入当前输入框。内容来自 Pin（已固定）和已启用的自定义分组，适用于支持第三方键盘的输入框；iPad 也可按相同步骤设置。

还未安装？[从 App Store 下载 PasteQ](https://apps.apple.com/cn/app/id6443971843)。

## 1. 准备要使用的文本

1. 打开 iPhone 上的 PasteQ，将一条常用文本加入 Pin 或自定义分组。
2. 如果文本来自 Mac，先按[多设备同步指南](./multi-device-sync)开启 iCloud 同步，并在 iPhone 的 PasteQ 中确认文本已经出现。
3. 在 PasteQ 的“设置 → 键盘快速输入”中，检查要显示的自定义分组是否已开启。Pin 始终包含在键盘中。

## 2. 在系统设置中添加键盘

1. 打开 iPhone“设置 → 通用 → 键盘 → 键盘”。
2. 点“添加新键盘…”，选择 PasteQ。
3. PasteQ 键盘不需要开启“允许完全访问”。

## 3. 切换键盘并点选文本

1. 打开一个支持第三方键盘的输入框，例如备忘录中的普通文本输入区。
2. 长按键盘上的地球键，切换到 PasteQ。
3. 选择 Pin 或需要的分组，点选一条文本，将它填入输入框。

如果点选未能填入，也可以长按记录复制，再在允许粘贴的输入框中手动粘贴。

## 键盘支持哪些内容？

- Pin 或已启用自定义分组中的文本、链接，以及富文本记录的纯文本内容。
- 图片、文件和加密记录不会作为可插入内容显示；键盘不保留富文本样式。
- 每组最多显示最近 100 条可用文本，超长文本会被截断。需要完整长文时，请回到 PasteQ App 查看和复制。
- 密码等安全输入框、部分专用输入框，以及禁用第三方键盘的 App 可能无法使用 PasteQ 键盘。

iOS 键盘不负责在后台采集其他 App 的剪贴板历史。Mac 上的历史记录和来源识别用法见[快速上手](./getting-started)。

## 新记录没有出现在键盘中？

键盘读取主 App 更新的本地内容。主 App 未运行时，键盘显示上次更新的内容，因此 Mac 上刚保存的文本不一定已经可用。

1. 打开 iPhone 上的 PasteQ；来自 Mac 的内容需先完成 iCloud 同步。
2. 确认文本已加入 Pin 或自定义分组，且该分组在“键盘快速输入”设置中处于开启状态。
3. 等待内容更新后，回到输入框重新切换到 PasteQ 键盘。
4. 若仍缺少某条记录，检查它是否为加密记录、图片或文件，以及是否超出每组显示范围。

如果完全找不到 PasteQ 键盘，先检查系统键盘列表是否已添加它，再到普通文本输入框中尝试。其他问题见[常见问题](./faq)，也可[联系我们](./contact)。
